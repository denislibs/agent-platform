What counts as a credit?
Credits are spent on model tokens and sandbox time. A typical research task uses 3–20 credits.
Can the agent use my accounts?
Only through connectors you add explicitly. The agent asks before any action with external effects.
Where do files live?
Results are copied to your library when a task finishes. Sandboxes are deleted afterwards.
