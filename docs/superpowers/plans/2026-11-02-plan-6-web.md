# План 6: веб-приложение — вход, главный экран, экран задачи, настройки, `web` за nginx

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пакет `apps/web` (`@agent/web`) на Preact + Vite из компонентов `@agent/ui`: вход по magic link и OAuth, главный экран с композером и вложениями, экран задачи с планом, лентой шагов из SSE, вопросом агента, ответом в Markdown и файлами, настройки с темой в профиле; сервис `web` за nginx в Docker и `bun run web:dev` без Docker; юнит-тесты экранов на happy-dom и сквозной тест в Playwright против настоящего API и воркера.

**Architecture:**
- **Приложение говорит с бэкендом только по HTTP.** `apps/web/src/**` импортирует из монорепозитория лишь `@agent/shared` (zod-схемы API) и `@agent/ui` (oxlint). Клиент API (`createApi`) проверяет каждый ответ схемой из `@agent/shared`, разбирает конверт ошибок API и форму ошибок Better Auth, на 401 переводит приложение на вход. Поток шагов — `EventSource` с отбрасыванием дублей по `seq` и переподключением с `?after=` после `stream_error`.
- **Состояние — сигналы** (`@preact/signals`, спецификация 12): сессия (профиль, баланс, настройки клиента), список задач сайдбара с курсором, стор экрана задачи (карточка из `GET /api/tasks/:id`, лента из SSE). Перевод статусов ядра и шагов в пропсы ui-kit — чистые функции в `src/view/` с таблицами из заметок плана 5.
- **Вид — только ui-kit.** Раскладка экранов (оболочка с сайдбаром, экран входа, знак продукта, страница настроек, «к содержимому») и стили Markdown переезжают в `@agent/ui` (`styles/layout.css`, `.ui-prose`); витрина переходит на них. У приложения нет ни одного CSS-файла — это проверяет тест. Markdown строится из mdast в VNode Preact, без `innerHTML`.
- **API получает то, что нужно клиенту:** публичный `GET /api/config` (настроенные провайдеры OAuth и предел файла), необязательный `questionSeq` в ответе на вопрос агента и тему в профиле (`user.theme`, `PATCH /api/me`).
- **Один origin.** В Docker браузер ходит на `http://localhost:8080`: nginx отдаёт `/` в Vite dev server (HMR по WebSocket), `/api/` — в API. Без Docker Vite на `:5173` проксирует `/api` на API, `BETTER_AUTH_URL=http://localhost:5173`. CSP страницы ставит Vite: хэш inline-скрипта темы считается из его текста.

**Tech Stack:** Bun 1.4.2, TypeScript 7, Preact 10.29.8, `preact-iso` 2.12.2, `@preact/signals` 2.11.3, zod 4.6.7, `mdast-util-from-markdown` 2.0.3 + `micromark-extension-gfm` 3.0.0 + `mdast-util-gfm` 3.1.0, `lucide-preact` 1.61.0, Vite 8.3.5 + `@preact/preset-vite` 2.10.6; тесты — happy-dom 21.0.4, `@testing-library/preact` 3.2.6, `@testing-library/user-event` 14.6.8, Playwright 1.64.1 (Chromium 1248); бэкенд — Hono 4.13, Better Auth 1.7.15, Drizzle, AWS SDK v3 (CORS бакета).

Спецификация: [2026-10-31-agent-platform-design.md](../specs/2026-10-31-agent-platform-design.md), разделы 2, 4, 10, 11, 12, 13. Дизайн-система: [design-system.md](../../design/design-system.md), витрина `packages/ui/showcase` (экраны входа и задачи — эталон вёрстки). ## Global Constraints

- Рантайм — Bun (локально 1.4.2). TypeScript 7 strict. Перед каждым коммитом — `bun run format` и `bun run check`, без ошибок и без предупреждений oxlint.
- **Версии новых зависимостей закреплены точно** (без `^`): в `apps/web` — `preact` 10.29.8, `preact-iso` 2.12.2, `@preact/signals` 2.11.3, `zod` 4.6.7, `lucide-preact` 1.61.0, `mdast-util-from-markdown` 2.0.3, `mdast-util-gfm` 3.1.0, `micromark-extension-gfm` 3.0.0, `@types/mdast` 4.0.4, `vite` 8.3.5, `@preact/preset-vite` 2.10.6, `@happy-dom/global-registrator` 21.0.4, `@testing-library/preact` 3.2.6, `@testing-library/user-event` 14.6.8, `@playwright/test` 1.64.1. Версии, совпадающие с ui-kit и lockfile, дают одну копию Preact и zod на приложение.
- **Граница приложения:** `apps/web/src/**` импортирует из `@agent/*` только `@agent/shared` и `@agent/ui`; запрещены остальные пакеты бэкенда, `bun`, `hono`, `better-auth`, `drizzle-orm`, `postgres`, `bullmq`, `ioredis`, `openai`, `awilix`, `@aws-sdk/*` (oxlint). Сквозной стенд бэкенда живёт в `packages/api/test`, а не в приложении.
- **Вид — только из ui-kit** (спецификация 12): у приложения нет своих CSS-файлов, каждый класс `ui-*` из `.tsx` приложения существует в стилях ui-kit (тест `apps/web/test/kit.test.ts`). Новая раскладка добавляется в ui-kit и появляется на витрине.
- **`test:unit` не требует Docker и инфраструктуры.** Тесты приложения — `bun run test:web`, отдельный процесс с `--preload ./apps/web/test/dom.ts` (happy-dom подменяет `fetch`, `Request`, `Response`); он входит в `test:unit` и `test`. Голый `bun test` пропускает `apps/web/**` (`pathIgnorePatterns`). Сквозной `bun run test:e2e:web` (Playwright, нужны `infra:up` и Chromium) не входит ни в `test:unit`, ни в `test`.
- **TDD:** тест пишется до реализации и проверяет поведение (что видит и делает пользователь, какие запросы уходят), а не разметку. Ожидание — `until()` из `test/render.tsx` без `expect` внутри (README ui-kit: неудачный `expect` в цикле ожидания медленный в Bun).
- **Безопасность:** ответ модели никогда не попадает в `innerHTML`; ссылки — только абсолютные `http(s)`/`mailto` через `safeHref`; CSP без `'unsafe-eval'` и без inline-скриптов, кроме скрипта темы по хэшу; загрузки — PUT в S3 ровно с подписанными `Content-Type` и длиной, без cookie.
- **Доступность:** заголовок вкладки на каждом экране, ориентиры (`aside`, `nav`, `main#main`), ссылка «Skip to content», фокус в `<main>` после перехода внутри приложения, живой регион статуса задачи.
- Тексты интерфейса — на английском (дизайн-система, «Тон интерфейса»), комментарии в коде — на русском. Секреты не коммитятся.

## Решения и отклонения

- **Пакет — `apps/web`** (`@agent/web`, спецификация 13), первый в `apps/`: корневой `workspaces` получает `"apps/*"`. Бэкенд остаётся в `packages/` (отклонение плана 4a). `bun install --frozen-lockfile --production` образа бэкенда без каталога `apps/` проверен: Bun пишет «skipped 1 workspace listed in bun.lock but not on disk» и ставит пакеты бэкенда — `docker/backend/Dockerfile` не меняется.
- **Без Tailwind (отклонение от спецификации 2).** ui-kit — обычный CSS на токенах, а дублировать в приложении то, что есть в ui-kit, нельзя (заметки плана 5). Раскладка экранов, которая жила в `showcase.css` витрины, переезжает в ui-kit: `styles/layout.css` — `ui-mark`, `ui-brand`, `ui-auth*`, `ui-shell*` (сайдбар, основная колонка, панель компьютера, подвал композера), `ui-center` (главный экран), `ui-page` (настройки), `ui-skip-link`; в `agent.css` — `.ui-prose` для Markdown. Витрина переходит на эти классы, тест стилей ui-kit проверяет их наличие. Узкие экраны: до 1100 px панель компьютера скрыта, до 900 px сайдбар встаёт над содержимым.
- **Preact 10.29.8, как ui-kit.** Переход ui-kit и приложения на Preact 11 — пункт backlog, его не трогаем.
- **Роутер — `preact-iso` 2.12.2** (спецификация 2): peer `preact >=10`, работает с Vite и happy-dom (проверено). `LocationProvider` перехватывает клики по всем ссылкам своего origin, поэтому ему задан `scope` `APP_LINKS = /^\/(?!api\/)/`: ссылка скачивания `/api/files/:id` уходит браузеру (redirect на presigned GET), а не в маршрутизатор — тест. Peer `preact-render-to-string` Bun ставит сам (6.8.2); в сборку он не попадает (нужен только `prerender`).
- **Состояние — `@preact/signals` 2.11.3** (спецификация 12): сессия, список задач и стор задачи — сигналы в состоянии приложения (`AppContext`); локальное состояние форм — хуки. `useMemo`/`useState` для создания сторов, `peek()` там, где эффект не должен подписываться.
- **Клиент API на схемах `@agent/shared`.** Каждый ответ проходит `safeParse`; несовпадение — `ApiRequestError('invalid_response')`, а не падение в глубине экрана. Ошибка — `ApiRequestError { status, code, message }`: код из конверта API или Better Auth (`{ message, code }`, заметки плана 4a), свои коды `network`, `invalid_response`, `upload_failed`. 401 вне `/api/auth/*` вызывает `onUnauthorized` — сессия становится `signed_out`, охрана маршрутов уводит на `/sign-in`. Запросы относительные с `credentials: 'same-origin'` (отклонение от «`include`» из задания: на свой origin cookie уходит и так, а `include` нужен только чужим). Изменяющие запросы — с JSON-телом: браузер ставит `Origin`, его проверяют `hono/csrf` и Better Auth.
- **zod в браузере — без JIT.** zod 4 при создании объектной схемы пробует `new Function('')`, и строгая CSP пишет `securitypolicyviolation` (нашёл сквозной тест). `src/zod-jitless.ts` вызывает `z.config({ jitless: true })` и импортируется в `main.tsx` первым — раньше, чем схемы `@agent/shared` создадут объекты. В `.oxlintrc.json` этот импорт без привязки разрешён рядом с `*.css`.
- **Провайдеры входа — `GET /api/config`.** Публичный (как `/api/health`), не под `/api/auth/*`: там весь путь отдан Better Auth. Ответ `ClientConfigSchema = { providers: ('google'|'github')[], uploadMaxBytes }` — кнопки только настроенных провайдеров и проверка размера файла до загрузки; `Cache-Control: no-store`.
- **`questionSeq` — seq паузы** (`status → waiting_user`), на которую отвечает клиент; необязательный (пункт backlog закрывается). Задан — API читает шаги начиная с него и принимает ответ, только если это единственная пауза с этого места; иначе 409 `conflict` («the agent has asked another question since»), ничего не пишется и не ставится. Клиент берёт seq из ленты (`pendingQuestion`), на 409 показывает тост и перечитывает задачу.
- **Тема — в профиле** (спецификация 12, заметки плана 5). Колонка `user.theme text NOT NULL DEFAULT 'dark'` (миграция `0003_user_theme`); Better Auth объявляет её `additionalFields.theme` с `input: false`, поэтому `getSession` отдаёт тему, а клиентский `/api/auth/update-user` её менять не может (проверено на 1.7.15: 400 `FIELD_NOT_ALLOWED`). Пишет только `PATCH /api/me { theme }` (zod `PROFILE_THEMES`) → `AuthGateway.setTheme` → `internalAdapter.updateUser` (проверено). `PROFILE_THEMES` в `@agent/shared` совпадает с `THEMES` ui-kit — тест. Клиент применяет тему профиля при входе (`setTheme` ui-kit, `localStorage['ui-theme']` — только кэш для первой отрисовки), в настройках — сразу на экране и затем в профиль; сбой сохранения возвращает прежнюю тему.
- **Markdown — mdast в VNode, без HTML-строк.** `mdast-util-from-markdown` 2.0.3 + GFM (`micromark-extension-gfm` 3.0.0, `mdast-util-gfm` 3.1.0, таблицы, зачёркивание, автоссылки, списки задач) строит дерево, `Markdown` рендерит узлы элементами Preact. Поэтому санитайзер не нужен: сырой HTML модели показывается текстом, картинки — ссылкой с подписью (чужие адреса не грузятся; CSP `img-src 'self' data:`), ссылки — только абсолютные `http(s)` и `mailto` через `safeHref` ui-kit, с `target="_blank" rel="noopener noreferrer nofollow"`; относительная ссылка («outputs/a.csv») вела бы на маршрут приложения — она текст. Код — `ui-codeblock`, таблицы — `ui-table`, инлайн-код — `ui-code`. Тест прогоняет 15 XSS-нагрузок.
- **Статусы ядра → ui-kit** — таблицы из заметок плана 5 в одном модуле `src/view/status.ts` с тестом на каждый статус. Лента: `toolEntries` сводит `llm_call.toolCalls` (аргументы) и `tool_result` (результат) по `toolCallId`; подпись, вид работы и подробность — `describeTool` по аргументам инструментов из `packages/agent/src/tools`.
- **Экран задачи — по витрине, а не по колонкам спецификации 12.** Эталон вёрстки — экран задачи витрины (задание): слева диалог, а план, шаги, вопрос агента, ответ и файлы — внутри `AgentMessage`; справа `ComputerPanel`. В спецификации план и шаги стоят в правой колонке. Шаги — одна `StepGroup` на всю задачу, а не только текущей подзадачи: сводка «Searched 2 queries · Wrote 1 file», раскрыта во время работы и свёрнута после.
- **Панель компьютера без скриншотов (отклонение от спецификации 12).** `screenshotPath` в шаге — путь внутри песочницы, API скриншотов не отдаёт. Панель показывает последний вызов инструмента песочницы (терминал, файлы, браузер, поиск; управляющие `create_plan`, `report`, `accept`… — нет): снимок страницы — Markdown, вывод терминала и файлов — моноширинным текстом, перемотка кнопками. Скриншоты — пункт backlog.
- **SSE.** Карточка задачи шагов не содержит, поэтому поток всегда открывается с `?after=0`; у финальной задачи API сразу отдаёт всю ленту и `end`. Шаг с `seq ≤` последнего отброшен (спецификация 10). Переподключение после штатного закрытия раз в 15 минут делает сам `EventSource` с `Last-Event-ID`; после `stream_error` и после отказа сервера (`readyState === CLOSED`) — модуль, с `?after=<последний seq>` и задержкой 1 → 2 → … → 30 с, сбрасываемой на `open`. Потеря связи перечитывает карточку: так же проверяется сессия (401 → вход) и существование задачи. Шаг `status` и управляющие сигналы (план, отчёт, решения, `finish`) перечитывают карточку; перечитывания во время чтения схлопываются в одно.
- **Вложения грузятся сразу при выборе.** До загрузки проверяются размер (`uploadMaxBytes` из `/api/config`), пустой файл, повтор имени (в песочнице все файлы лежат в `inputs/<имя>`) и предел 20 файлов. PUT — с заголовками ровно из ответа API и `credentials: 'omit'`; `Content-Length` браузер ставит сам. Тип — из `File.type` без параметров или `application/octet-stream`.
- **CORS бакета.** Браузер шлёт PUT с `Content-Type` на чужой origin (S3) — нужен preflight. `allowBrowserUploads(cfg, origins)` в `@agent/storage` (AWS SDK живёт только там) дописывает origin в правило `browser-uploads` и не трогает чужие правила; идемпотентно. Вызывают его `bun run s3:cors` (по умолчанию `BETTER_AUTH_URL` и `http://localhost:5173`), разовый сервис `s3-cors` в compose и стенд сквозного теста (`http://localhost:5199`). **Не проверено на Garage** во время планирования (менять CORS общего dev-бакета было нельзя): интеграционный тест `packages/storage/test/cors.test.ts` — первая проверка; если Garage назовёт ошибку отсутствия CORS иначе, чем `NoSuchCORSConfiguration`, или не примет `ID` правила, поправить по факту.
- **CSP ставит Vite**, один источник: `contentSecurityPolicy()` в `apps/web/csp.ts` считает `'sha256-…'` из текста `themeBootScript` (`node:crypto`), Vite отдаёт заголовок на каждый ответ dev-сервера. `default-src 'self'`; `script-src 'self' 'sha256-…'`; `style-src 'self' 'unsafe-inline'` — только потому, что dev-сервер Vite вставляет CSS тегами `<style>` (стили Floating UI и Preact через `element.style` CSP не ограничивает); `img-src 'self' data:`; `connect-src 'self' <origin S3> <ws HMR>`; `object-src 'none'`, `base-uri 'none'`, `form-action 'none'` (формы отправляются через `fetch`), `frame-ancestors 'none'`. nginx в `location /` CSP не добавляет (две политики браузер применил бы обе), а повторяет остальные заголовки безопасности: свой `add_header` в `location` отменяет наследование от `server` (заметки плана 4b). Для `/api/` остаётся deny-all CSP. Сквозной тест падает на любом `securitypolicyviolation`. Продакшен-сборка без `'unsafe-inline'` — план 7.
- **Vite запускается с `--configLoader native`:** Bun импортирует `vite.config.ts` сам, и Vite не пишет рядом собранный `vite.config.ts.timestamp-*.mjs` — так dev-сервер работает в контейнере с корнем только для чтения (проверено: образ собирается, Vite отвечает с `read_only`, `cap_drop: ALL`). Кэш зависимостей — `VITE_CACHE_DIR=/tmp/vite` (tmpfs). `vite.config.ts` берёт `themeBootScript` из нового экспорта `@agent/ui/theme`, чтобы не грузить компоненты в конфиг.
- **Docker.** `docker/web/Dockerfile` — dev-образ с dev-зависимостями (Vite), пользователь `bun`; сервис `web` (profile `app`) монтирует только исходники (`apps/web/src`, `index.html`, `packages/ui/src|styles`, `packages/shared/src`) для HMR, наружу не публикуется, `read_only`, без capabilities, healthcheck через `bun -e fetch`. nginx: `upstream web`, `location /` с `Upgrade`/`Connection` через `map` (HMR по WebSocket) и `proxy_read_timeout 3600s`, `depends_on.web: service_healthy, restart: true`. Vite знает публичный origin (`WEB_PUBLIC_ORIGIN=http://localhost:8080`): HMR-клиент подключается к порту 8080, этот же origin — в CSP. `WEB_WATCH_POLL=1` включает опрос файлов, если bind-mount не доносит события. Проверено: `nginx -t`, `docker compose config`, сборка образа и Vite в нём. **Не проверено:** весь стек (`stack:up`) с HMR через nginx — шаг проверки в задаче 13.
- **Без Docker:** `bun run web:dev` (Vite на `http://localhost:5173`, прокси `/api` → `API_PROXY_TARGET`, по умолчанию `http://localhost:3000`) и API с `BETTER_AUTH_URL=http://localhost:5173` (заметки плана 4a: Better Auth сверяет Origin с этим адресом).
- **Сессия продлевается** вызовом `GET /api/auth/get-session` раз в 10 минут, пока вкладка видима (пункт backlog плана 4a): охрана API обновлённый cookie не пересылает, а Better Auth в `get-session` — да. `null` → вход.
- **Вход.** Magic link: `POST /api/auth/sign-in/magic-link { email, callbackURL: '/', errorCallbackURL: '/sign-in' }` — ссылка из письма после входа ведёт на `/`, а битая или просроченная — на `/sign-in?error=INVALID_TOKEN` (проверено), экран показывает понятный алерт. OAuth: `POST /api/auth/sign-in/social` → `{ url }` → `window.location.assign(url)`. Выход: `POST /api/auth/sign-out` без тела (проверено: 200). Состояние «Check your email» — регион `role="status"`.

async function isLastPause(tx: TxRepositories, taskId: string, questionSeq: number): Promise<boolean> {

  return { user: { id, email, name, image, theme }, balance: { millicredits, credits: formatCredits(millicredits) } };
}

export function meRoutes(app: Hono<ApiEnv>, deps: ApiDeps): void {
  app.get('/api/me', async c => c.json(await meBody(deps, c.get('user'))));

  /** Тема интерфейса в профиле (спецификация 12): веб-приложение применяет её при входе на любом устройстве. */
  app.patch('/api/me', async c => {
    const { theme } = await parseJson(c, UpdateMeBodySchema);
    const user = c.get('user');
    await deps.auth.setTheme(user.id, theme);
    return c.json(await meBody(deps, { ...user, theme }));
  });

/** Сессии без Better Auth: cookie `session=<token>`, выданный signIn. Только для тестов. */
export class FakeAuth implements AuthGateway {
  private readonly sessions = new Map<string, SessionUser>();

  signIn(user: SessionUser): string {
    const token = crypto.randomUUID();
    this.sessions.set(token, user);
    return token;
  }

  async handler(req: Request): Promise<Response> {
    return new Response(`fake auth: ${new URL(req.url).pathname}`, { status: 200 });
  }

  async session(headers: Headers): Promise<SessionUser | undefined> {
    const token = /(?:^|;\s*)session=([^;]+)/.exec(headers.get('cookie') ?? '')?.[1];
    return token ? this.sessions.get(token) : undefined;
  }

  /** Как профиль в базе: тема меняется во всех сессиях пользователя. */
  async setTheme(userId: string, theme: ProfileTheme): Promise<void> {
    for (const [token, user] of this.sessions) if (user.id === userId) this.sessions.set(token, { ...user, theme });
  }
}

import { createHash } from 'node:crypto';
import type { Plugin } from 'vite';
import { themeBootScript } from '@agent/ui/theme';

/** Источник CSP для inline-скрипта: `'sha256-<base64>'` от его текста ровно в том виде, в каком он стоит в HTML. */
export function scriptHash(script: string): string {
  return `'sha256-${createHash('sha256').update(script, 'utf8').digest('base64')}'`;
}

/** Тема до первой отрисовки: themeBootScript первым в <head> (README ui-kit), как плагин витрины. */
export function themeBoot(): Plugin {
  return {
    name: 'theme-boot',
    transformIndexHtml: () => [{ tag: 'script', children: themeBootScript, injectTo: 'head-prepend' }],
  };
}

export interface CspOptions {
  /** Публичный адрес S3 (S3_PUBLIC_ENDPOINT): туда браузер грузит файлы по presigned PUT. */
  s3Endpoint: string;
  /** WebSocket HMR dev-сервера, как его видит браузер: ws://localhost:5173 или ws://localhost:8080 за nginx. */
  hmrOrigin: string;
}

/**
 * CSP приложения в разработке (заметки плана 4b и 5): скрипты — только свои и inline-скрипт темы по хэшу;
 * соединения — свой origin, S3 и HMR. `style-src 'unsafe-inline'` нужен dev-серверу Vite (CSS приходит тегами
 * <style>); стили, которые ставят Floating UI и Preact через element.style, CSP не ограничивает. Продакшен-сборка
 * (план 7) отдаёт CSS файлами и обходится без 'unsafe-inline'.
 */
export function contentSecurityPolicy({ s3Endpoint, hmrOrigin }: CspOptions): string {
  return [
    "default-src 'self'",
    `script-src 'self' ${scriptHash(themeBootScript)}`,
    "style-src 'self' 'unsafe-inline'",
    "img-src 'self' data:",
    "font-src 'self'",
    `connect-src 'self' ${new URL(s3Endpoint).origin} ${hmrOrigin}`,
    "object-src 'none'",
    "base-uri 'none'",
    "form-action 'none'",
    "frame-ancestors 'none'",
  ].join('; ');
}

import { z } from 'zod';
import {
  ApiErrorSchema,
  ClientConfigSchema,
  MeResponseSchema,
  TaskEnvelopeSchema,
  TaskListResponseSchema,
  TaskResponseSchema,
  UploadResponseSchema,
  type AuthProvider,
  type ProfileTheme,
} from '@agent/shared';

/** Сколько задач в странице сайдбара. */
export const TASKS_PAGE = 20;

/**
 * Ошибка запроса к API. code — код из конверта API (`not_found`, `too_many_active_tasks`…), код Better Auth
 * (`INVALID_EMAIL`…) или свой: `network` (сервер недоступен), `invalid_response` (ответ не прошёл схему),
 * `upload_failed` (S3 отклонил загрузку). message готов к показу пользователю.
 */
export class ApiRequestError extends Error {
  constructor(
    readonly status: number,
    readonly code: string,
    message: string,
  ) {
    super(message);
    this.name = 'ApiRequestError';
  }
}

/** Ошибки /api/auth/* приходят в форме Better Auth, а не в конверте API (заметки плана 4a). */
const BetterAuthErrorSchema = z.object({ message: z.string(), code: z.string().optional() });
const BetterAuthOkSchema = z.object({ status: z.boolean() }).loose();
const SignOutSchema = z.object({ success: z.boolean() });
const SocialRedirectSchema = z.object({ url: z.url(), redirect: z.boolean() });
/** get-session: null без сессии; поля сессии приложению не нужны — только факт входа. */
const SessionSchema = z
  .object({ user: z.object({ id: z.string() }).loose() })
  .loose()
  .nullable();

interface Schema<T> {
  safeParse(value: unknown): { success: true; data: T } | { success: false };
}

function toRequestError(status: number, body: unknown): ApiRequestError {
  const ours = ApiErrorSchema.safeParse(body);
  if (ours.success) return new ApiRequestError(status, ours.data.error.code, ours.data.error.message);
  const auth = BetterAuthErrorSchema.safeParse(body);
  if (auth.success) return new ApiRequestError(status, auth.data.code ?? 'auth_error', auth.data.message);
  return new ApiRequestError(status, status >= 500 ? 'internal' : 'bad_request', `The server answered ${status}.`);
}

export interface ApiOptions {
  fetch?: (input: string, init: RequestInit) => Promise<Response>;
  /** 401 вне /api/auth/*: сессия кончилась — приложение уводит на вход. */
  onUnauthorized?(): void;
}

const task = (id: string) => `/api/tasks/${encodeURIComponent(id)}`;

/** Куда вернуть пользователя после входа по ссылке или через OAuth и куда — при ошибке ссылки. */
const AUTH_REDIRECTS = { callbackURL: '/', errorCallbackURL: '/sign-in' } as const;

/**
 * Клиент API на схемах @agent/shared: каждый ответ проверяется во время выполнения. Запросы относительные
 * (тот же origin, cookie сессии уходит сама); изменяющие — с JSON-телом: браузер ставит Origin, и его проверяют
 * csrf API и Better Auth.
 */
export function createApi(opts: ApiOptions = {}) {
  const doFetch = opts.fetch ?? ((input: string, init: RequestInit) => fetch(input, init));

  async function send<T>(method: string, path: string, schema: Schema<T>, body?: unknown): Promise<T> {
    let res: Response;
    try {
      res = await doFetch(path, {
        method,
        credentials: 'same-origin',
        headers:
          body === undefined
            ? { accept: 'application/json' }
            : { accept: 'application/json', 'content-type': 'application/json' },
        ...(body === undefined ? {} : { body: JSON.stringify(body) }),
      });
    } catch {
      throw new ApiRequestError(0, 'network', 'Could not reach the server. Check your connection and try again.');
    }
    const data: unknown = await res.json().catch(() => undefined);
    if (!res.ok) {
      if (res.status === 401 && !path.startsWith('/api/auth/')) opts.onUnauthorized?.();
      throw toRequestError(res.status, data);
    }
    const parsed = schema.safeParse(data);
    if (!parsed.success)
      throw new ApiRequestError(res.status, 'invalid_response', 'The server sent an unexpected response.');
    return parsed.data;
  }

  return {
    config: () => send('GET', '/api/config', ClientConfigSchema),
    me: () => send('GET', '/api/me', MeResponseSchema),
    setTheme: (theme: ProfileTheme) => send('PATCH', '/api/me', MeResponseSchema, { theme }),
    listTasks: (before?: string) =>
      send(
        'GET',
        `/api/tasks?limit=${TASKS_PAGE}${before === undefined ? '' : `&before=${encodeURIComponent(before)}`}`,
        TaskListResponseSchema,
      ),
    getTask: (id: string) => send('GET', task(id), TaskResponseSchema),
    createTask: (prompt: string, fileIds: readonly string[]) =>
      send('POST', '/api/tasks', TaskEnvelopeSchema, { prompt, fileIds }),
    /** questionSeq — seq паузы, на которую отвечаем: устаревший ответ API отклонит 409. */
    reply: (id: string, text: string, questionSeq?: number) =>
      send(
        'POST',
        `${task(id)}/messages`,
        TaskEnvelopeSchema,
        questionSeq === undefined ? { text } : { text, questionSeq },
      ),
    cancel: (id: string) => send('POST', `${task(id)}/cancel`, TaskEnvelopeSchema),
    declareUpload: (body: { name: string; contentType: string; size: number }) =>
      send('POST', '/api/uploads', UploadResponseSchema, body),
    sendMagicLink: (email: string) =>
      send('POST', '/api/auth/sign-in/magic-link', BetterAuthOkSchema, { email, ...AUTH_REDIRECTS }),
    /** Адрес провайдера OAuth: браузер уходит туда сам (window.location.assign). */
    socialSignIn: async (provider: AuthProvider) =>
      (await send('POST', '/api/auth/sign-in/social', SocialRedirectSchema, { provider, ...AUTH_REDIRECTS })).url,
    signOut: () => send('POST', '/api/auth/sign-out', SignOutSchema),
    /** Продлевает cookie сессии (Better Auth обновляет его в ответе get-session); false — сессии нет. */
    touchSession: async () => (await send('GET', '/api/auth/get-session', SessionSchema)) !== null,
  };
}

export type Api = ReturnType<typeof createApi>;

import type { FileDto } from '@agent/shared';
import { ApiRequestError, type Api } from './client.ts';

/** Формат contentType, который принимает POST /api/uploads: тип без параметров. */
const MIME = /^[\w.+-]+\/[\w.+-]+$/;

/** Тип для подписи: из File.type без параметров; пустой или странный — application/octet-stream. */
export function uploadContentType(file: Pick<File, 'type'>): string {
  const type = file.type.split(';')[0]!.trim().toLowerCase();
  return type.length <= 127 && MIME.test(type) ? type : 'application/octet-stream';
}

export type PutFn = (url: string, init: RequestInit) => Promise<Response>;

/**
 * Загрузка входного файла: объявить (POST /api/uploads) → PUT прямо в S3 по presigned URL → FileDto для fileIds.
 * Подпись S3 включает Content-Type и Content-Length: тип — ровно из ответа API, длину браузер ставит сам по File.
 */
export async function uploadFile(api: Api, file: File, put: PutFn = (url, init) => fetch(url, init)): Promise<FileDto> {
  const declared = await api.declareUpload({ name: file.name, contentType: uploadContentType(file), size: file.size });
  let res: Response;
  try {
    res = await put(declared.upload.url, {
      method: declared.upload.method,
      headers: declared.upload.headers,
      body: file,
      // Чужой origin (S3): cookie и прочие учётные данные туда не нужны.
      credentials: 'omit',
    });
  } catch {
    throw new ApiRequestError(0, 'network', `Could not upload ${file.name}. Check your connection and try again.`);
  }
  if (!res.ok)
    throw new ApiRequestError(res.status, 'upload_failed', `The storage refused ${file.name} (HTTP ${res.status}).`);
  return declared.file;
}

import type { EventSourceLike } from '../src/api/events.ts';

/** EventSource для тестов: события подаются вручную, открытые источники — в FakeEventSource.all. */
export class FakeEventSource implements EventSourceLike {
  static all: FakeEventSource[] = [];
  static reset() {
    FakeEventSource.all = [];
  }
  static get last(): FakeEventSource {
    return FakeEventSource.all.at(-1)!;
  }

  readyState = 0;
  closed = false;
  private readonly listeners = new Map<string, Array<(event: MessageEvent<string>) => void>>();

  constructor(readonly url: string) {
    FakeEventSource.all.push(this);
  }

  addEventListener(type: string, listener: (event: MessageEvent<string>) => void): void {
    this.listeners.set(type, [...(this.listeners.get(type) ?? []), listener]);
  }

  close(): void {
    this.closed = true;
    this.readyState = 2;
  }

  emit(type: string, data: unknown = {}, id?: string): void {
    const event = new MessageEvent<string>(type, { data: JSON.stringify(data), lastEventId: id ?? '' });
    for (const listener of this.listeners.get(type) ?? []) listener(event);
  }

  open(): void {
    this.readyState = 1;
    this.emit('open');
  }

  /** Сбой соединения: readyState 0 — браузер переподключится сам, 2 — сдался. */
  fail(readyState: 0 | 2): void {
    this.readyState = readyState;
    for (const listener of this.listeners.get('error') ?? []) listener(new MessageEvent<string>('error'));
  }
}

/** Ручные таймеры: run() выполняет всё запланированное. */
export function manualTimers() {
  const pending = new Map<number, { fn: () => void; ms: number }>();
  let next = 1;
  return {
    setTimer: (fn: () => void, ms: number) => {
      const id = next++;
      pending.set(id, { fn, ms });
      return id;
    },
    clearTimer: (id: unknown) => void pending.delete(id as number),
    delays: () => [...pending.values()].map(t => t.ms),
    run() {
      const due = [...pending.values()];
      pending.clear();
      for (const t of due) t.fn();
    },
  };
}

import { StepDtoSchema, StreamEndSchema, type StepDto, type StreamEnd } from '@agent/shared';

/** То, что нужно от EventSource: тесты подставляют свой источник. */
export interface EventSourceLike {
  readonly readyState: number;
  addEventListener(type: string, listener: (event: MessageEvent<string>) => void): void;
  close(): void;
}
export type EventSourceFactory = (url: string) => EventSourceLike;

/** EventSource.CLOSED: браузер сдался (ответ не 200) и сам переподключаться не будет. */
const CLOSED = 2;
const RETRY_MIN_MS = 1000;
const RETRY_MAX_MS = 30_000;

export interface TaskEventHandlers {
  /** Новый шаг: каждый seq — ровно один раз и по возрастанию (дубли отброшены, спецификация 10). */
  onStep(step: StepDto): void;
  /** Задача в финальном статусе, все шаги отправлены; поток закрыт и больше не откроется. */
  onEnd(end: StreamEnd): void;
  /** Связь потеряна (false) и восстановлена (true): приложение перечитывает задачу и сессию. */
  onConnection?(connected: boolean): void;
}

export interface TaskEventsOptions extends TaskEventHandlers {
  taskId: string;
  /** Шаги до этого seq уже есть у клиента. */
  afterSeq?: number;
  createSource?: EventSourceFactory;
  setTimer?: (fn: () => void, ms: number) => unknown;
  clearTimer?: (handle: unknown) => void;
}

/**
 * Живой поток шагов задачи (GET /api/tasks/:id/events). Сам EventSource переподключается после штатного закрытия
 * потока раз в 15 минут и шлёт Last-Event-ID. Этот модуль добавляет: отбрасывание дублей по seq, закрытие по end,
 * переподключение с ?after= после stream_error и после отказа сервера (CLOSED) — с задержкой до 30 с.
 */
export function openTaskEvents(opts: TaskEventsOptions): { close(): void } {
  const createSource = opts.createSource ?? ((url: string) => new EventSource(url));
  const setTimer = opts.setTimer ?? ((fn: () => void, ms: number) => setTimeout(fn, ms));
  const clearTimer = opts.clearTimer ?? ((handle: unknown) => clearTimeout(handle as ReturnType<typeof setTimeout>));
  let lastSeq = opts.afterSeq ?? 0;
  let source: EventSourceLike | undefined;
  let timer: unknown;
  let retryMs = RETRY_MIN_MS;
  let closed = false;
  let connected = true;

  const setConnected = (value: boolean) => {
    if (value === connected) return;
    connected = value;
    opts.onConnection?.(value);
  };

  const stop = () => {
    source?.close();
    source = undefined;
    if (timer !== undefined) clearTimer(timer);
    timer = undefined;
  };

  const reconnectLater = () => {
    stop();
    setConnected(false);
    timer = setTimer(() => {
      timer = undefined;
      connect();
    }, retryMs);
    retryMs = Math.min(retryMs * 2, RETRY_MAX_MS);
  };

  function connect(): void {
    if (closed) return;
    const url = `/api/tasks/${encodeURIComponent(opts.taskId)}/events?after=${lastSeq}`;
    const current = createSource(url);
    source = current;
    current.addEventListener('open', () => {
      retryMs = RETRY_MIN_MS;
      setConnected(true);
    });
    current.addEventListener('step', event => {
      const parsed = StepDtoSchema.safeParse(JSON.parse(event.data));
      if (!parsed.success || parsed.data.seq <= lastSeq) return;
      lastSeq = parsed.data.seq;
      opts.onStep(parsed.data);
    });
    current.addEventListener('end', event => {
      closed = true;
      stop();
      setConnected(true);
      opts.onEnd(StreamEndSchema.parse(JSON.parse(event.data)));
    });
    // Сбой чтения на сервере: поток закрывается, переподключаемся сами с последним seq.
    current.addEventListener('stream_error', () => reconnectLater());
    // Сбой соединения. CONNECTING — EventSource переподключится сам (с Last-Event-ID); CLOSED — сдался, решаем мы.
    current.addEventListener('error', () => {
      if (current !== source) return;
      if (current.readyState === CLOSED) reconnectLater();
      else setConnected(false);
    });
  }

  connect();
  return {
    close() {
      closed = true;
      stop();
    },
  };
}

import { batch, signal } from '@preact/signals';
import { isTerminalTask, type FileDto, type StepDto, type SubtaskDto, type TaskDetail } from '@agent/shared';
import { ApiRequestError, type Api } from '../api/client.ts';
import { openTaskEvents, type TaskEventsOptions } from '../api/events.ts';

/** Управляющие сигналы инструментов, после которых меняются подзадачи или итог: карточку надо перечитать. */
const PLAN_CONTROLS = new Set(['create_plan', 'report', 'accept', 'revise', 'replan', 'finish']);

function changesTheTask(step: StepDto): boolean {
  const { payload } = step;
  if (payload.type === 'status') return true;
  return (
    payload.type === 'tool_result' &&
    typeof payload.control?.kind === 'string' &&
    PLAN_CONTROLS.has(payload.control.kind)
  );
}

export interface TaskStoreDeps {
  api: Api;
  /** Тесты подставляют свой поток. */
  openEvents?: (opts: TaskEventsOptions) => { close(): void };
}

/**
 * Состояние экрана задачи на сигналах (спецификация 12): карточка задачи из GET /api/tasks/:id, лента шагов из SSE.
 * Шаг status или управляющий сигнал (план, отчёт, решение) перечитывает карточку — подзадачи, итог и файлы;
 * параллельные перечитывания схлопываются в одно следующее.
 */
export function createTaskStore(deps: TaskStoreDeps, taskId: string) {
  const task = signal<TaskDetail | null>(null);
  const subtasks = signal<SubtaskDto[]>([]);
  const files = signal<FileDto[]>([]);
  const steps = signal<StepDto[]>([]);
  const error = signal<ApiRequestError | null>(null);
  /** Поток на связи; false — переподключается. */
  const connected = signal(true);
  let stream: { close(): void } | undefined;
  let refreshing: Promise<void> | undefined;
  let dirty = false;
  let disposed = false;

  async function load(): Promise<void> {
    const res = await deps.api.getTask(taskId);
    if (disposed) return;
    batch(() => {
      task.value = res.task;
      subtasks.value = res.subtasks;
      files.value = res.files;
      error.value = null;
    });
  }

  /** Перечитать карточку; вызов во время чтения ставит ещё одно чтение после него. */
  function refresh(): Promise<void> {
    if (refreshing) {
      dirty = true;
      return refreshing;
    }
    refreshing = (async () => {
      try {
        for (;;) {
          dirty = false;
          await load();
          if (!dirty || disposed) break;
        }
      } catch (err) {
        if (!disposed)
          error.value = err instanceof ApiRequestError ? err : new ApiRequestError(0, 'network', String(err));
      } finally {
        refreshing = undefined;
      }
    })();
    return refreshing;
  }

  async function start(): Promise<void> {
    await refresh();
    if (disposed || !task.value) return;
    // Шагов в карточке нет: поток с нуля отдаёт всю ленту, у финальной задачи — и сразу end.
    stream = (deps.openEvents ?? openTaskEvents)({
      taskId,
      afterSeq: 0,
      onStep: step => {
        steps.value = [...steps.value, step];
        if (changesTheTask(step)) void refresh();
      },
      onEnd: () => void refresh(),
      onConnection: value => {
        connected.value = value;
        // Пропала связь: проверить задачу и сессию (401 уведёт на вход, 404 — задачи больше нет).
        if (!value) void refresh();
      },
    });
  }

  return {
    task,
    subtasks,
    files,
    steps,
    error,
    connected,
    start,
    refresh,
    /** Ответ на вопрос агента; questionSeq — пауза, на которую отвечаем. */
    async reply(text: string, questionSeq: number | undefined): Promise<void> {
      task.value = (await deps.api.reply(taskId, text, questionSeq)).task;
    },
    async cancel(): Promise<void> {
      task.value = (await deps.api.cancel(taskId)).task;
      await refresh();
    },
    get finished(): boolean {
      return task.value !== null && isTerminalTask(task.value.status);
    },
    dispose(): void {
      disposed = true;
      stream?.close();
    },
  };
}

export type TaskStore = ReturnType<typeof createTaskStore>;

/** Вызов инструмента в ленте: аргументы из llm_call, результат из tool_result (их связывает toolCallId). */
export interface ToolEntry {
  /** seq шага tool_result. */
  seq: number;
  subtaskId: string | null;
  tool: string;
  /** «Searching "agent frameworks"». */
  label: string;
  ok: boolean;
  output: string;
  /** Для панели компьютера: «Using Browser» и адрес, путь или команда. */

  markdown: boolean;

const LABEL_LIMIT = 90;

function clip(text: string, limit = LABEL_LIMIT): string {
  const line = text.replace(/\s+/g, ' ').trim();
  return line.length > limit ? `${line.slice(0, limit - 1)}…` : line;
}

const str = (args: unknown, key: string): string | undefined => {
  const value = args && typeof args === 'object' ? (args as Record<string, unknown>)[key] : undefined;
  return typeof value === 'string' || typeof value === 'number' ? String(value) : undefined;

/** Строка шага, вид работы и подробность по имени инструмента и его аргументам (спецификация 5). */
export function describeTool(
  tool: string,
  args: unknown,
): { label: string; activity: string; detail?: string; markdown?: boolean } {
  const path = str(args, 'path');
  switch (tool) {
    case 'web_search': {
      const query = str(args, 'query') ?? '';
      return { label: `Searching "${clip(query, 60)}"`, activity: 'Using Search', detail: query };

    case 'browser_open': {

    case 'browser_click':
      return { label: `Clicking element ${str(args, 'id') ?? ''}`.trim(), activity: 'Using Browser', markdown: true };

    case 'file_edit':

    case 'ask_user':
      return { label: 'Asking you a question', activity: 'Waiting for you' };
    case 'create_plan':

    case 'replan':
      return { label: 'Changing the plan', activity: 'Planning' };
    case 'finish':

    default:

  }

/** Вызовы инструментов в порядке ленты: аргументы — из вызова модели с тем же toolCallId. */
export function toolEntries(steps: readonly StepDto[]): ToolEntry[] {
  const args = new Map<string, unknown>();
  const entries: ToolEntry[] = [];
  for (const s of steps) {
    const p = s.payload;
    if (p.type === 'llm_call') for (const call of p.toolCalls) args.set(call.id, call.args);
    if (p.type !== 'tool_result') continue;
    const described = describeTool(p.name, args.get(p.toolCallId));
    entries.push({
      seq: s.seq,
      subtaskId: s.subtaskId,
      tool: p.name,
      label: described.label,
      ok: p.ok,
      output: p.output,
      activity: described.activity,
      markdown: described.markdown ?? false,
      ...(described.detail ? { detail: described.detail } : {}),
    });
  }
  return entries;
}

/** Управляющие инструменты агента: план, вопрос, отчёт и решения — не работа «на компьютере». */
const CONTROL_TOOLS = new Set(['ask_user', 'create_plan', 'report', 'accept', 'revise', 'replan', 'finish']);

/** Кадры панели компьютера: только работа в песочнице — терминал, файлы, браузер, поиск. */
export const computerEntries = (entries: readonly ToolEntry[]): ToolEntry[] =>
  entries.filter(e => !CONTROL_TOOLS.has(e.tool));

const COUNTERS: Array<[tools: string[], one: string, many: string]> = [
  [['web_search'], 'Searched 1 query', 'Searched # queries'],
  [['browser_open'], 'Browsed 1 page', 'Browsed # pages'],
  [['shell'], 'Ran 1 command', 'Ran # commands'],
  [['file_write', 'file_edit'], 'Wrote 1 file', 'Wrote # files'],
  [['file_read', 'file_list'], 'Read 1 file', 'Read # files'],
];

/** Сводка свёрнутой ленты: «Searched 2 queries · Browsed 1 page · Ran 3 commands» (дизайн-система). */
export function summarize(entries: readonly ToolEntry[]): string {
  const parts = COUNTERS.flatMap(([tools, one, many]) => {
    const n = entries.filter(e => tools.includes(e.tool)).length;
    return n === 0 ? [] : [n === 1 ? one : many.replace('#', String(n))];
  });
  return parts.length > 0 ? parts.join(' · ') : `${entries.length} ${entries.length === 1 ? 'step' : 'steps'}`;
}

/** Вопрос агента, на который ждут ответа: seq паузы (для questionSeq), seq вопроса и его текст. */
export interface PendingQuestion {
  pauseSeq: number;
  askSeq: number | null;
  question: string;
}

const askOf = (s: StepDto): string | null =>
  s.payload.type === 'tool_result' &&
  s.payload.control?.kind === 'ask_user' &&
  typeof s.payload.control.question === 'string'
    ? s.payload.control.question
    : null;

const isUserMessage = (s: StepDto): boolean => s.agent === 'user' && s.payload.type === 'message';

export function pendingQuestion(steps: readonly StepDto[]): PendingQuestion | null {
  const pause = steps.findLastIndex(s => s.payload.type === 'status' && s.payload.to === 'waiting_user');
  if (pause === -1) return null;
  // После паузы уже ответили — вопрос закрыт, даже если задача ещё не снялась с паузы.
  if (steps.slice(pause + 1).some(isUserMessage)) return null;
  const ask = steps.slice(0, pause).findLast(s => askOf(s) !== null);
  return {
    pauseSeq: steps[pause]!.seq,
    askSeq: ask?.seq ?? null,
    question: (ask && askOf(ask)) ?? 'The agent needs your input to continue.',
  };
}

export interface DialogueItem {
  seq: number;
  role: 'agent' | 'user';
  text: string;
}

/** Переписка после запроса: вопросы агента (ask_user) и ответы пользователя по порядку ленты. */
export function conversation(steps: readonly StepDto[]): DialogueItem[] {
  // Первое сообщение пользователя — сам запрос: его показывает UserMessage с prompt задачи.
  const prompt = steps.find(isUserMessage)?.seq;
  return steps.flatMap((s): DialogueItem[] => {
    const question = askOf(s);
    if (question !== null) return [{ seq: s.seq, role: 'agent', text: question }];
    if (isUserMessage(s) && s.seq !== prompt && s.payload.type === 'message')
      return [{ seq: s.seq, role: 'user', text: s.payload.text }];
    return [];
  });
}

/** Причина сбоя задачи из шага status → failed (API уже очистил её от путей хоста). */
export function failureReason(steps: readonly StepDto[]): string | null {
  const failed = steps.findLast(s => s.payload.type === 'status' && s.payload.to === 'failed');
  return failed?.payload.type === 'status' ? (failed.payload.reason ?? null) : null;
}

```tsx
import type { ComponentChildren } from 'preact';
import { useMemo } from 'preact/hooks';
import type { Nodes, Parents, Root, TableRow } from 'mdast';
import { fromMarkdown } from 'mdast-util-from-markdown';
import { gfmFromMarkdown } from 'mdast-util-gfm';
import { gfm } from 'micromark-extension-gfm';
import { safeHref } from '@agent/ui';

/**
 * Адрес ссылки из Markdown модели: только абсолютные http(s) и mailto. Небезопасные схемы отбрасывает safeHref
 * ui-kit; относительный адрес («outputs/a.csv», «/settings») вёл бы на маршрут приложения — тоже текст.
 */
export function markdownHref(url: string): string | undefined {
  const href = safeHref(url.trim());
  return href !== undefined && /^(?:https?:\/\/|mailto:)/i.test(href) ? href : undefined;
}

export function parseMarkdown(text: string): Root {
  return fromMarkdown(text, { extensions: [gfm()], mdastExtensions: [gfmFromMarkdown()] });
}

type Definitions = Map<string, string>;

function collectDefinitions(tree: Root): Definitions {
  const found: Definitions = new Map();
  const walk = (node: Nodes) => {
    if (node.type === 'definition') found.set(node.identifier, node.url);
    if ('children' in node) for (const child of node.children) walk(child);
  };
  walk(tree);
  return found;
}

function link(href: string | undefined, children: ComponentChildren, key: number) {
  const safe = href === undefined ? undefined : markdownHref(href);
  if (safe === undefined) return <span key={key}>{children}</span>;
  return (
    <a key={key} class="ui-link" href={safe} target="_blank" rel="noopener noreferrer nofollow">
      {children}
    </a>
  );
}

function row(
  r: TableRow,
  cell: 'th' | 'td',
  align: readonly (string | null | undefined)[],
  defs: Definitions,
  key: number,
) {
  return (
    <tr key={key}>
      {r.children.map((c, i) => {
        const Cell = cell;
        const a = align[i];
        return (
          <Cell key={i} {...(a ? { align: a as 'left' | 'right' | 'center' } : {})}>
            {renderChildren(c, defs)}
          </Cell>
        );
      })}
    </tr>
  );
}

function renderChildren(node: Parents, defs: Definitions): ComponentChildren {
  return node.children.map((child, i) => render(child, defs, i));
}

/**
 * Узел mdast → VNode Preact. Разметка строится элементами, без innerHTML: сырой HTML модели показывается как текст,
 * картинки — ссылкой с подписью (чужие адреса не грузятся), ссылки проходят markdownHref.
 */
function render(node: Nodes, defs: Definitions, key: number): ComponentChildren {
  switch (node.type) {
    case 'root':
      return renderChildren(node, defs);
    case 'paragraph':
      return <p key={key}>{renderChildren(node, defs)}</p>;
    case 'heading': {
      const Tag = `h${node.depth}` as 'h1';
      return <Tag key={key}>{renderChildren(node, defs)}</Tag>;
    }
    case 'thematicBreak':
      return <hr key={key} class="ui-divider" />;
    case 'blockquote':
      return <blockquote key={key}>{renderChildren(node, defs)}</blockquote>;
    case 'list':
      return node.ordered ? (
        <ol key={key} start={node.start ?? undefined}>
          {renderChildren(node, defs)}
        </ol>
      ) : (
        <ul key={key}>{renderChildren(node, defs)}</ul>
      );
    case 'listItem':
      return (
        <li key={key}>
          {node.checked === true ? '☑ ' : node.checked === false ? '☐ ' : null}
          {renderChildren(node, defs)}
        </li>
      );
    case 'code':
      return (
        <div key={key} class="ui-codeblock">
          {node.lang && <div class="ui-codeblock__head">{node.lang}</div>}
          <pre>
            <code>{node.value}</code>
          </pre>
        </div>
      );
    case 'html':
      return node.value;
    case 'text':
      return node.value;
    case 'emphasis':
      return <em key={key}>{renderChildren(node, defs)}</em>;
    case 'strong':
      return <strong key={key}>{renderChildren(node, defs)}</strong>;
    case 'delete':
      return <del key={key}>{renderChildren(node, defs)}</del>;
    case 'inlineCode':
      return (
        <code key={key} class="ui-code">
          {node.value}
        </code>
      );
    case 'break':
      return <br key={key} />;
    case 'link':
      return link(node.url, renderChildren(node, defs), key);
    case 'linkReference':
      return link(defs.get(node.identifier), renderChildren(node, defs), key);
    case 'image':
      return link(node.url, node.alt || node.url, key);
    case 'imageReference':
      return link(defs.get(node.identifier), node.alt || node.label || '', key);
    case 'table': {
      const [head, ...body] = node.children;
      const align = node.align ?? [];
      return (
        <div key={key} class="ui-table-wrap">
          <table class="ui-table">
            {head && <thead>{row(head, 'th', align, defs, 0)}</thead>}
            <tbody>{body.map((r, i) => row(r, 'td', align, defs, i))}</tbody>
          </table>
        </div>
      );
    }
    case 'definition':
      return null;
    case 'footnoteReference':
      return `[${node.label ?? node.identifier}]`;
    case 'footnoteDefinition':
      return (
        <div key={key}>
          [{node.label ?? node.identifier}] {renderChildren(node, defs)}
        </div>
      );
    default:
      // Узлы расширений, которых здесь нет (yaml, math…): содержимое как текст.
      return 'children' in node ? renderChildren(node as Parents, defs) : 'value' in node ? String(node.value) : null;
  }
}

/** Безопасный Markdown ответа агента и снимков страниц (спецификация 12, заметки плана 5). */
export function Markdown({ text }: { text: string }) {
  const content = useMemo(() => {
    const tree = parseMarkdown(text);
    return render(tree, collectDefinitions(tree), 0);
  }, [text]);
  return <div class="ui-prose">{content}</div>;
}

import { batch, signal } from '@preact/signals';
import { setTheme } from '@agent/ui';
import type { ClientConfig, MeResponse, ProfileTheme } from '@agent/shared';
import { ApiRequestError, type Api } from '../api/client.ts';

export type SessionStatus = 'loading' | 'signed_in' | 'signed_out' | 'unreachable';

/**
 * Сессия: профиль и баланс (GET /api/me), публичные настройки (GET /api/config). Тема из профиля применяется
 * при входе (спецификация 12); localStorage ui-kit — только кэш для первой отрисовки.
 */
export function createSession(api: Api) {
  const status = signal<SessionStatus>('loading');
  const me = signal<MeResponse | null>(null);
  const config = signal<ClientConfig | null>(null);

  const applyProfile = (profile: MeResponse) => {
    batch(() => {
      me.value = profile;
      status.value = 'signed_in';
    });
    setTheme(profile.user.theme);
  };

  return {
    status,
    me,
    config,
    async load(): Promise<void> {
      const [cfg, profile] = await Promise.allSettled([api.config(), api.me()]);
      if (cfg.status === 'fulfilled') config.value = cfg.value;
      if (profile.status === 'fulfilled') return applyProfile(profile.value);
      const err = profile.reason;
      status.value = err instanceof ApiRequestError && err.status === 401 ? 'signed_out' : 'unreachable';
    },
    /** Баланс после задачи: тихо, без смены статуса при сбое. */
    async refresh(): Promise<void> {
      try {
        applyProfile(await api.me());
      } catch {
        // 401 уже перевёл сессию в signed_out через onUnauthorized; прочее — покажем старый баланс.
      }
    },
    /** Тема сразу на экране, затем в профиле; ошибка сохранения возвращает прежнюю и пробрасывается. */
    async saveTheme(theme: ProfileTheme): Promise<void> {
      const previous = me.value?.user.theme;
      setTheme(theme);
      try {
        me.value = await api.setTheme(theme);
      } catch (err) {
        if (previous) setTheme(previous);
        throw err;
      }
    },
    async signOut(): Promise<void> {
      await api.signOut();
      this.signedOut();
    },
    signedOut(): void {
      batch(() => {
        me.value = null;
        status.value = 'signed_out';
      });
    },
  };
}

export type Session = ReturnType<typeof createSession>;

import { batch, signal } from '@preact/signals';
import type { TaskSummary } from '@agent/shared';
import { ApiRequestError, type Api } from '../api/client.ts';

/** Список задач сайдбара: первая страница, «Load more» по курсору, обновление одной задачи на месте. */
export function createTaskList(api: Api) {
  const items = signal<TaskSummary[]>([]);
  const nextCursor = signal<string | null>(null);
  const loading = signal(false);
  /** Первая страница пришла: до этого «No tasks yet» не показывается. */
  const loaded = signal(false);
  const error = signal<ApiRequestError | null>(null);

  async function fetchPage(before: string | undefined, merge: (page: TaskSummary[]) => TaskSummary[]) {
    loading.value = true;
    try {
      const page = await api.listTasks(before);
      batch(() => {
        items.value = merge(page.tasks);
        nextCursor.value = page.nextCursor;
        loaded.value = true;
        error.value = null;
      });
    } catch (err) {
      if (err instanceof ApiRequestError) error.value = err;
    } finally {
      loading.value = false;
    }
  }

  return {
    items,
    nextCursor,
    loading,
    loaded,
    error,
    /** Первая страница заново; уже подгруженные «старые» страницы отбрасываются. */
    reload: () => fetchPage(undefined, page => page),
    /** Следующая страница; задачи, которые уже есть (сдвиг из-за новых задач), не дублируются. */
    async more(): Promise<void> {
      if (nextCursor.value === null || loading.value) return;
      await fetchPage(nextCursor.value, page => {
        const known = new Set(items.value.map(t => t.id));
        return [...items.value, ...page.filter(t => !known.has(t.id))];
      });
    },
    /** Новая задача — в начало; известная — заменяется на месте (статус с экрана задачи). */
    upsert(task: TaskSummary): void {
      const at = items.value.findIndex(t => t.id === task.id);
      items.value = at === -1 ? [task, ...items.value] : items.value.map(t => (t.id === task.id ? task : t));
    },
    clear(): void {
      batch(() => {
        items.value = [];
        nextCursor.value = null;
        loaded.value = false;
      });
    },
  };
}

export type TaskList = ReturnType<typeof createTaskList>;

/** Коды, с которыми Better Auth возвращает на /sign-in после ссылки (errorCallbackURL). */
const LINK_ERRORS: Record<string, string> = {
  INVALID_TOKEN: 'This sign-in link is invalid or was already used. Request a new one.',
  EXPIRED_TOKEN: 'This sign-in link has expired. Request a new one.',
};

/** Вход (спецификация 12): фон «поле точек», OAuth — только настроенные провайдеры (GET /api/config), magic link. */
export function SignIn() {
  usePage('Sign in');
  const { api, session, assign } = useApp();
  const { query } = useLocation();
  const { theme, setTheme } = useTheme();
  const [email, setEmail] = useState('');
  const [sentTo, setSentTo] = useState<string | null>(null);
  const [busy, setBusy] = useState<'email' | AuthProvider | null>(null);
  const [error, setError] = useState<string | null>(() =>
    query.error ? (LINK_ERRORS[query.error] ?? 'Sign-in did not work. Try again.') : null,
  );
  const providers = session.config.value?.providers ?? [];
  const address = email.trim();

  const sendLink = async (event: Event) => {
    event.preventDefault();
    if (!EMAIL.test(address) || busy) return;
    setBusy('email');
    setError(null);
    try {
      await api.sendMagicLink(address);
      setSentTo(address);
    } catch (err) {
      setError(errorText(err));
    } finally {
      setBusy(null);
    }
  };

  const continueWith = async (provider: AuthProvider) => {
    setBusy(provider);
    setError(null);
    try {
      // Better Auth отдаёт адрес провайдера; браузер уходит туда и вернётся на / с cookie сессии.
      assign(await api.socialSignIn(provider));
    } catch (err) {
      setError(errorText(err));
      setBusy(null);
    }
  };

  return (
    <main id={MAIN_ID} class="ui-auth" tabIndex={-1}>
      <DotField />
      <div class="ui-brand ui-auth__brand">
        <span class="ui-mark" />
        agent
      </div>

        <SegmentedControl
          label="Theme"
          value={theme}
          onChange={setTheme}
          options={[

            { value: 'dark', icon: Moon, ariaLabel: 'Dark theme' },
            { value: 'auto', icon: Monitor, ariaLabel: 'System theme' },
          ]}
        />
      </div>
      {sentTo ? (
        <div class="ui-auth__card">
          <h1 class="ui-display">
            Check your <em>email.</em>
          </h1>
          <p class="ui-auth__lead" role="status">
            We sent a sign-in link to {sentTo}. It works once and expires in 15 minutes.
          </p>
          <Button block onClick={() => setSentTo(null)}>
            Use a different email
          </Button>
        </div>
      ) : (
        <form class="ui-auth__card" onSubmit={event => void sendLink(event)} noValidate>
          <h1 class="ui-display">
            Hand it <em>off.</em>
          </h1>
          <p class="ui-auth__lead">Sign in to give your agent its first task.</p>

            </Alert>

  );

import { fileKind, type FileKind } from '@agent/ui';

const KIND_NAMES: Record<FileKind, string> = {
  sheet: 'Spreadsheet',
  doc: 'Document',
  slides: 'Slides',
  code: 'Code',
  other: 'File',
};

/** «394 B», «84 KB», «1.2 MB» — как на карточках файлов витрины. */
export function formatBytes(bytes: number): string {
  if (bytes < 1024) return `${bytes} B`;
  const units = ['KB', 'MB', 'GB'];
  let value = bytes / 1024;
  let unit = 0;
  while (value >= 1024 && unit < units.length - 1) {
    value /= 1024;
    unit++;
  }
  return `${value >= 10 ? Math.round(value) : Math.round(value * 10) / 10} ${units[unit]}`;
}

/** Подпись карточки файла: «Spreadsheet · 84 KB». */
export const fileMeta = (name: string, size: number): string => `${KIND_NAMES[fileKind(name)]} · ${formatBytes(size)}`;

/** Имя файла без каталогов: outputs/report.csv → report.csv. */
export const baseName = (path: string): string => path.split('/').pop() || path;

import { useRef, useState } from 'preact/hooks';
import { useLocation } from 'preact-iso';
import { Paperclip } from 'lucide-preact';
import { Alert, Attachment, Composer, IconButton, useToast } from '@agent/ui';
import { MAX_FILES_PER_TASK, type FileDto } from '@agent/shared';
import { uploadFile } from '../api/uploads.ts';
import { usePage } from '../layout/page.ts';
import { Shell } from '../layout/shell.tsx';
import { useApp } from '../state/app.ts';
import { errorText } from '../view/errors.ts';
import { fileMeta, formatBytes } from '../view/format.ts';

interface PendingFile {
  key: string;
  file: File;
  state: 'uploading' | 'ready' | 'failed';
  dto?: FileDto;
}

/** Главный экран (спецификация 12): композер новой задачи с вложениями; задачи — в сайдбаре. */
export function Home() {
  usePage('New task');
  const { api, session, tasks } = useApp();
  const { route } = useLocation();
  const toast = useToast();
  const picker = useRef<HTMLInputElement>(null);
  const [text, setText] = useState('');
  const [files, setFiles] = useState<PendingFile[]>([]);
  const [sending, setSending] = useState(false);
  const maxBytes = session.config.value?.uploadMaxBytes ?? Number.POSITIVE_INFINITY;
  const outOfCredits = (session.me.value?.balance.millicredits ?? 1) <= 0;

  const update = (key: string, patch: Partial<PendingFile>) =>
    setFiles(list => list.map(f => (f.key === key ? { ...f, ...patch } : f)));

  // Файл грузится сразу при выборе: к отправке задачи он, как правило, уже в S3.
  const attach = (picked: File[]) => {
    const names = new Set(files.map(f => f.file.name));
    const accepted: PendingFile[] = [];
    for (const file of picked) {
      if (files.length + accepted.length >= MAX_FILES_PER_TASK) {
        toast.show({ tone: 'warning', title: `Up to ${MAX_FILES_PER_TASK} files per task` });
        break;
      }
      // В песочнице все файлы лежат в inputs/<имя>: API отклонит два файла с одним именем.
      if (names.has(file.name)) {
        toast.show({ tone: 'warning', title: `${file.name} is already attached` });
        continue;
      }
      if (file.size === 0 || file.size > maxBytes) {
        toast.show({
          tone: 'warning',
          title: `${file.name} cannot be attached`,
          description: file.size === 0 ? 'The file is empty.' : `Files are limited to ${formatBytes(maxBytes)}.`,
        });
        continue;
      }
      names.add(file.name);
      accepted.push({ key: crypto.randomUUID(), file, state: 'uploading' });
    }
    setFiles(list => [...list, ...accepted]);
    for (const pending of accepted) {
      uploadFile(api, pending.file).then(
        dto => update(pending.key, { state: 'ready', dto }),
        err => {
          update(pending.key, { state: 'failed' });
          toast.show({ tone: 'danger', title: `Could not upload ${pending.file.name}`, description: errorText(err) });
        },
      );
    }
  };

  const submit = async (prompt: string) => {
    if (files.some(f => f.state === 'uploading')) {
      toast.show({ tone: 'info', title: 'Wait for the uploads to finish' });
      return;
    }
    if (files.some(f => f.state === 'failed')) {
      toast.show({ tone: 'warning', title: 'Remove the files that failed to upload' });
      return;
    }
    setSending(true);
    try {
      const { task } = await api.createTask(
        prompt,
        files.flatMap(f => (f.dto ? [f.dto.id] : [])),
      );
      tasks.upsert(task);
      route(`/tasks/${encodeURIComponent(task.id)}`);
    } catch (err) {
      setSending(false);
      toast.show({ tone: 'danger', title: 'The task did not start', description: errorText(err) });
    }
  };

  return (
    <Shell>
      <div class="ui-center">
        <h1 class="ui-display">What should your agent do?</h1>
        {outOfCredits && (
          <Alert tone="warning" title="You are out of credits">
            New tasks will not start until credits are added.
          </Alert>
        )}
        <Composer
          value={text}
          onValueChange={setText}
          onSubmit={value => void submit(value)}
          disabled={sending}
          placeholder="Give your agent a task"
          attachments={
            files.length > 0 &&
            files.map(f => (
              <Attachment
                key={f.key}
                name={f.file.name}
                meta={
                  f.state === 'uploading'
                    ? 'Uploading…'
                    : f.state === 'failed'
                      ? 'Upload failed'
                      : fileMeta(f.file.name, f.file.size)
                }
                onRemove={() => setFiles(list => list.filter(x => x.key !== f.key))}
              />
            ))
          }
          tools={
            <>
              <IconButton icon={Paperclip} label="Attach files" onClick={() => picker.current?.click()} />
              <input
                ref={picker}
                type="file"
                multiple
                class="ui-sr-only"
                tabIndex={-1}
                aria-hidden="true"
                onChange={event => {
                  attach([...(event.currentTarget.files ?? [])]);
                  event.currentTarget.value = '';
                }}
              />
            </>
          }
        />
      </div>
    </Shell>
  );
}
```

import { useState } from 'preact/hooks';
import { ComputerPanel } from '@agent/ui';
import { Markdown } from '../view/markdown.tsx';
import type { ToolEntry } from '../view/timeline.ts';

/**
 * Панель компьютера: последний вызов инструмента (live) или выбранный кнопками перемотки. Снимок страницы — Markdown,
 * вывод терминала и файлов — текстом как есть (ComputerPanel моноширинный). Скриншотов нет: они остаются в песочнице.
 */
export function TaskComputer({ entries }: { entries: readonly ToolEntry[] }) {
  const [selected, setSelected] = useState<number | null>(null);
  const last = entries.length - 1;
  const index = selected === null ? last : Math.min(selected, last);
  const entry = index >= 0 ? entries[index] : undefined;
  const live = selected === null || index === last;
  return (
    <ComputerPanel
      activity={entry?.activity ?? 'Starting'}
      detail={entry ? entry.detail : 'sandbox'}
      position={entries.length === 0 ? 100 : ((index + 1) / entries.length) * 100}
      live={live}
      {...(index > 0 ? { onPrevious: () => setSelected(index - 1) } : {})}
      {...(index >= 0 && index < last ? { onNext: () => setSelected(index + 1 === last ? null : index + 1) } : {})}
      onJumpToLive={() => setSelected(null)}
    >
      {entry ? entry.markdown ? <Markdown text={entry.output} /> : entry.output : null}
    </ComputerPanel>
  );
}

/** Секунды работы: от создания до конца (или до сейчас, пока задача жива), тикает раз в секунду. */
function useElapsed(task: TaskDetail | null): number {
  const [now, setNow] = useState(() => Date.now());
  const live = task !== null && !isTerminalTask(task.status);
  useEffect(() => {
    if (!live) return;
    const timer = setInterval(() => setNow(Date.now()), 1000);
    return () => clearInterval(timer);
  }, [live]);
  if (!task) return 0;
  const end = task.finishedAt ? Date.parse(task.finishedAt) : now;
  return Math.max(0, (end - Date.parse(task.createdAt)) / 1000);
}

/** Экран задачи (спецификация 12, эталон — экран задачи на витрине): диалог, план, шаги, ответ, компьютер. */
export function TaskScreen({ id }: { id: string }) {
  const app = useApp();
  const toast = useToast();
  const store = useMemo(() => createTaskStore({ api: app.api, openEvents: app.openEvents }, id), [app, id]);
  const [stepsOpen, setStepsOpen] = useState(true);
  const task = store.task.value;
  const steps = store.steps.value;
  usePage(task ? taskTitle(task.prompt) : 'Task');

  useEffect(() => {
    void store.start();
    return () => store.dispose();
  }, [store]);
  // Сайдбар видит статус открытой задачи сразу; по завершении — новый баланс.
  const status = task?.status;
  useEffect(() => {
    const current = store.task.peek();
    if (!current) return;
    app.tasks.upsert(current);
    if (isTerminalTask(current.status)) {
      setStepsOpen(false);
      void app.session.refresh();
    }
  }, [app, store, status]);

  const elapsed = useElapsed(task);
  const entries = useMemo(() => toolEntries(steps), [steps]);
  const question = task?.status === 'waiting_user' ? pendingQuestion(steps) : null;
  const dialogue = useMemo(() => conversation(steps), [steps]);

  if (store.error.value && !task) {
    return (
      <Shell>
        <div class="ui-center">
          {store.error.value.code === 'not_found' ? (
            <EmptyState icon={SearchX} title="Task not found" description="It may belong to another account." />
          ) : (
            <Alert
              tone="danger"
              title="Could not load the task"
              actions={<Button onClick={() => void store.start()}>Retry</Button>}
            >
              {store.error.value.message}
            </Alert>
          )}
        </div>
      </Shell>
    );
  }
  if (!task) {
    return (
      <Shell>
        <div class="ui-center">
          <Spinner label="Loading the task" />
        </div>
      </Shell>
    );
  }

  const working = isWorking(task.status);
  const outputs = store.files.value.filter(f => f.kind === 'output');
  const inputs = store.files.value.filter(f => f.kind === 'input');

  const answer = async (text: string) => {
    try {
      await store.reply(text, question?.pauseSeq);
    } catch (err) {
      toast.show({ tone: 'danger', title: 'The answer was not sent', description: errorText(err) });
      void store.refresh();
    }
  };
  const stop = async () => {
    try {
      await store.cancel();
    } catch (err) {
      toast.show({ tone: 'danger', title: 'Could not stop the task', description: errorText(err) });
    }
  };

  return (
    <Shell computer={<TaskComputer entries={computerEntries(entries)} />}>
      <div class="ui-shell__body">
        <h1 class="ui-sr-only">{taskTitle(task.prompt)}</h1>
        <div id="task-status" class="ui-sr-only" role="status">
          {statusAnnouncement(task)}
        </div>
        <UserMessage>{task.prompt}</UserMessage>
        {inputs.map(f => (
          <FileCard key={f.id} name={baseName(f.path)} meta={fileMeta(f.path, f.size)} href={f.url} />
        ))}
        <AgentMessage
          working={working}
          elapsed={elapsed}
          mark={<span class="ui-mark ui-mark--sm" />}
          onShowDetails={() => setStepsOpen(true)}
        >
          {store.subtasks.value.length > 0 && (
            <>
              <AgentText>Here's my plan:</AgentText>
              <PlanList items={planItems(store.subtasks.value)} />
            </>
          )}
          {entries.length > 0 && (
            <StepGroup
              summary={working ? `${entries.length} steps` : summarize(entries)}
              expanded={stepsOpen}
              onExpandedChange={setStepsOpen}
            >
              {entries.map((e, i) => (
                <Step key={e.seq} tool={e.tool} active={working && i === entries.length - 1} error={!e.ok}>
                  {e.label}
                </Step>
              ))}
            </StepGroup>
          )}
          {dialogue
            .filter(m => m.seq !== question?.askSeq)
            .map(m =>
              m.role === 'agent' ? (
                <AgentText key={m.seq}>{m.text}</AgentText>
              ) : (
                <UserMessage key={m.seq}>{m.text}</UserMessage>
              ),
            )}
          {working && <Thinking label={workingLabel(task.status)} />}
          {question && <AskCard question={question.question} onAnswer={text => void answer(text)} />}
          {task.status === 'done' && (
            <>
              {task.partial && (
                <Alert tone="warning" title="Partial result">

          {task.status === 'cancelled' && (

          />
          <small>Agents can make mistakes. Check important results.</small>

}

/** Охрана маршрутов: без сессии — только вход; с сессией вход не нужен. 401 посреди работы переводит сюда же. */
function Routes() {
  const { session, api } = useApp();
  const { path, route } = useLocation();
  const status = session.status.value;
  const onSignIn = path === '/sign-in';

  useEffect(() => {
    void session.load();
  }, [session]);
  useEffect(() => {
    if (status === 'signed_out' && !onSignIn) route('/sign-in', true);
    if (status === 'signed_in' && onSignIn) route('/', true);
  }, [status, onSignIn, route]);
  // Продление сессии (backlog плана 4a): охрана API не пересылает обновлённый cookie, а get-session — да.
  useEffect(() => {
    if (status !== 'signed_in') return;
    const timer = setInterval(() => {
      if (document.visibilityState !== 'visible') return;
      api.touchSession().then(
        alive => alive || session.signedOut(),
        () => undefined,
      );
    }, SESSION_TOUCH_MS);
    return () => clearInterval(timer);
  }, [status, api, session]);

  if (status === 'unreachable')
    return (
      <Splash>
        <Alert
          tone="danger"
          title="Cannot reach the server"
          actions={<Button onClick={() => void session.load()}>Retry</Button>}
        >
          Check your connection and try again.
        </Alert>
      </Splash>
    );
  if (status === 'loading' || (status === 'signed_out') !== onSignIn)
    return (
      <Splash>
        <Spinner size="lg" label="Loading" />
      </Splash>
    );
  return (
    <Router>
      <Route path="/sign-in" component={SignIn} />
      <Route path="/" component={Home} />
      <Route path="/tasks/:id" component={TaskScreen} />
      <Route path="/settings" component={SettingsPage} />
      <Route default component={NotFound} />
    </Router>
  );
}

/** Веб-приложение: состояние, тосты, роутер (ссылки /api/ уходят браузеру — APP_LINKS). */
export function App({ deps }: { deps?: AppDeps }) {
  // Одно состояние на всё время жизни приложения.
  const [state] = useState(() => createAppState(deps));
  return (
    <ToastProvider>
      <AppContext.Provider value={state}>
        <LocationProvider scope={APP_LINKS}>
          <Routes />
        </LocationProvider>
      </AppContext.Provider>
    </ToastProvider>
  );
}

import { GetBucketCorsCommand, PutBucketCorsCommand, S3Client, type CORSRule } from '@aws-sdk/client-s3';
import type { FileStoreConfig } from './index';

/** Правило CORS бакета для загрузок из браузера; остальные правила бакета не трогаются. */
export const BROWSER_UPLOADS_RULE_ID = 'browser-uploads';

async function currentRules(s3: S3Client, bucket: string): Promise<CORSRule[]> {
  try {
    return (await s3.send(new GetBucketCorsCommand({ Bucket: bucket }))).CORSRules ?? [];
  } catch (err) {
    // У бакета ещё нет CORS: S3 отвечает NoSuchCORSConfiguration.
    if (err instanceof Error && err.name === 'NoSuchCORSConfiguration') return [];
    throw err;
  }
}

/**
 * Разрешает браузеру с этих origin загружать файлы по presigned PUT (план 4a): preflight с Content-Type.
 * Origin добавляются к уже разрешённым (идемпотентно) — dev-стек, локальный Vite и e2e делят один бакет.
 * Возвращает итоговый список origin. Скачивание — переход по ссылке, CORS ему не нужен.
 */
export async function allowBrowserUploads(cfg: FileStoreConfig, origins: readonly string[]): Promise<string[]> {
  const s3 = new S3Client({
    endpoint: cfg.endpoint,
    region: cfg.region,
    forcePathStyle: true,
    credentials: { accessKeyId: cfg.accessKeyId, secretAccessKey: cfg.secretAccessKey },
    requestChecksumCalculation: 'WHEN_REQUIRED',
    responseChecksumValidation: 'WHEN_REQUIRED',
  });
  try {
    const rules = await currentRules(s3, cfg.bucket);
    const ours = rules.find(rule => rule.ID === BROWSER_UPLOADS_RULE_ID);
    const allowed = [...new Set([...(ours?.AllowedOrigins ?? []), ...origins.map(o => new URL(o).origin)])].toSorted();
    const rule: CORSRule = {
      ID: BROWSER_UPLOADS_RULE_ID,
      AllowedOrigins: allowed,
      AllowedMethods: ['PUT'],
      AllowedHeaders: ['content-type'],
      MaxAgeSeconds: 3600,
    };
    await s3.send(
      new PutBucketCorsCommand({
        Bucket: cfg.bucket,
        CORSConfiguration: { CORSRules: [...rules.filter(r => r.ID !== BROWSER_UPLOADS_RULE_ID), rule] },
      }),
    );
    return allowed;
  } finally {
    s3.destroy();
  }
}

  const email = url.searchParams.get('email') ?? '';
