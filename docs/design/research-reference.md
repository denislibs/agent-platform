# Исследование референса (manus.im) — сырые заметки

Только для ориентира при создании своей дизайн-системы. Логотип, название,
иллюстрации и ассеты референса не используем.

## Страница входа (тёмная тема)

### Фон
- Цвет страницы: `#050505` (`--background-gray-login`).
- Анимация — Lottie, отрисованный в SVG 3840×2160 по центру экрана, обрезан `overflow: hidden`.
- Устройство:
  - базовый слой — PNG-текстура сетки мелких точек (шаг ≈ 12 px), белые точки с прозрачностью ~0.18;
  - 7 «пятен» с линейными градиентами (розовый, бирюзово-синий, зелёный, оранжево-персиковый,
    красный, жёлтый, голубой), каждое с opacity 0.5, медленно дрейфуют вокруг центра
    (смещение ~100–150 px за 1.5 с), масштаб и поворот плавно колеблются;
  - пятна видны только через маску той же сетки точек — точки «подсвечиваются» цветом,
    где проходит пятно. Сплошных цветных пятен нет.
- Итоговое впечатление: почти чёрный экран, тусклая сетка точек, по которой медленно
  плывут едва заметные цветные переливы.

### Типографика
- Системный стек: `-apple-system, system-ui, "Segoe UI Variable Display", "Segoe UI", Helvetica, Arial, sans-serif`.
- Заголовок: 24/30, weight 500, `#e6e6e6`.
- Текст: 14/20, weight 400–500.
- Шкала: 12, 13 (label), 14, 16, 18, 20, 24, 28, 30.

### Компоненты
- Кнопка OAuth: высота 40, радиус 10, фон `#242424`, текст белый 14/500,
  иконка провайдера слева, бейдж «Last used» справа (синий текст на `#1a93fe1f`).
- Поле ввода: высота 40, радиус 8, фон `#242424`, текст `#e6e6e6`, padding 4/6/4/12.
- Основная кнопка (неактивна): фон `#939393`, текст `#000000e5`, радиус 8.
- Вторичная кнопка: фон `#242424`, текст `#e6e6e6`, радиус 8.
- Разделитель «Or»: тонкая линия `#ffffff0f` с подписью `#8c8c8c`.
- Колонка формы ≈ 348 px по центру.

### Токены (тёмная тема, выборка)
- Текст: primary `#e6e6e6`, secondary `#b3b3b3`, tertiary `#8c8c8c`, quaternary `#7a7a7a`,
  disable `#595959`, blue `#1a93fe`.
- Фоны: main `#1a1a1a`, card `#1c1c1c`, surface/menu `#242424`, secondary `#313131`,
  nav `#1f1f1f`, login `#050505`, маска диалога `#0009`.
- Заливки поверх фона (прозрачный белый): `#ffffff0a`, `#ffffff0f`, `#ffffff14`, `#ffffff1a`.
- Границы: main `#ffffff0f`, light `#ffffff08`, dark `#ffffff1f`, input-active `#ffffff52`.
- Акцент: `#1a93fe` (кнопка, иконки, ссылки), disabled `#215d93`.
- Статусы: success `#25ba3b`, warning `#f1a403`, error `#f25a5a` / `#eb4d4d`.
- Тени: XS `#00000014`, S `#00000029`, M `#00000047`, L `#0006`, highlight `#ffffff24`.
- Радиусы: small 8, row 10, card 12, composer (поле ввода задачи) 22.

## Внутри приложения

### Онбординг
Пройден до исследования: ссылки онбординга, включая шаг `selectPlan`, перенаправляют
в приложение. Выбор плана изучен через модалку тарифов (ниже).

### Каркас
- Фон контента `#242424`, текст по умолчанию 16/24 `#e6e6e6`.
- Боковая панель: фон `#1f1f1f`, ширина 300 px в раскрытом виде и 52 px в свёрнутом (только иконки,
  подсказка с названием и горячей клавишей при наведении, например «New task ⌘⇧O»).
  - Вверху: логотип, поиск, кнопка сворачивания.
  - Пункты: New task, Computers, Agents (с бейджем), Library, Websites, Automations, Plugins, More.
    Строка: иконка 16–20 px + текст 14/400, отступ между ними 4–8 px.
  - Секции «Projects» и «Tasks»: заголовок 13/500 `#8c8c8c`; пустое состояние 14 `#8c8c8c`.
  - Внизу: промо-карточка («пригласи друга — получи кредиты», заголовок serif), аватар,
    имя 14/500, иконки устройств и уведомлений.
- Верхняя полоса: выбор модели («Manus 2.0 Lite ▾», 16/500) слева; справа пилюля
  «Free plan | Upgrade» (серый текст + синяя ссылка) и счётчик кредитов с иконкой искры.

### Главный экран
- Колонка контента ≈ 672–768 px по центру.
- Логотип-словесный знак (serif) крупно вверху.
- Карточки сценариев: Build (сайты, приложения, игры), Create (слайды, картинки, видео),
  «Start from a local file»; фон карточек `#1c1c1c`–`#2a2a2a`, радиус 12–16,
  справа декоративная линейная иллюстрация, иконка категории цветная (синяя, оранжевая).
  Бейдж «Studio only»: 12/400 `#b3b3b3` на `#ffffff0f`, радиус pill.
- Лента примеров с превью (Video / App / Image) — бейдж типа с иконкой поверх картинки.
- Блок «Suggested for you»: фон `#242424`, радиус 24, тень; три карточки-подсказки
  (иконка источника + 2 строки текста), кнопки «обновить» и «закрыть».
- **Поле ввода задачи (composer)** — главный элемент:
  - верхняя полоса `#1c1c1c` с радиусом 22 22 0 0 и чипами «Cloud», «Choose project»
    (14 `#b3b3b3`, pill);
  - основное поле `#242424`, рамка 1 px `#ffffff1f`, радиус 22, высота ≈ 120;
  - placeholder «Assign a task or type / for more»;
  - снизу слева: «+» (вложения) и кнопка инструментов; справа: голосовой режим,
    микрофон, круглая кнопка отправки (неактивна — серая).

### Модалка тарифов
- Окно: фон `#1a1a1a`, радиус 20, ширина 1100, затемнение фона.
- Заголовок serif **Libre Baskerville** 28/34, weight 400. Serif используется точечно:
  заголовки модалок, промо и словесный знак. Весь интерфейс — системный sans.
- Переключатель Monthly / «Annually · Save 17%»: сегмент-контрол 13 px.
- Три карточки планов; выбранная/рекомендуемая — рамка синего акцента.
  - Цена крупно (≈ 32/600), старая цена зачёркнута серым, «/ month» 14 `#8c8c8c`.
  - Бейдж «50% OFF»: 12/500 `#1a93fe` на `#1a93fe1f`, радиус 6.
  - Кнопка основного плана: pill (радиус 9999), высота 40, `#1a93fe`, белый текст 14/500.
  - Остальные кнопки: pill, фон `#fffffff2`, текст `#000000e5`.
  - Выпадающий список объёма кредитов (рамка `#ffffff0f`, радиус 8).
  - Список фич: иконка 16 px + текст 14 `#e6e6e6`, межстрочный шаг ≈ 30 px.
- Ниже — строки-баннеры: «Teams & Enterprise» (serif-заголовок + кнопка-контур «Get Team»),
  «Security and Compliance» (значки сертификатов + «Learn more ↗»).

### Модель монетизации референса (для справки)
Free с ежедневными «refresh»-кредитами; платные планы отличаются объёмом кредитов в месяц;
лимиты на параллельные и запланированные задачи; скидка на первый месяц; годовая оплата −17 %.

### Экран задачи
Изучен на тестовой задаче (сравнение GitHub-фреймворков → CSV, ~1.5 мин).
- **Сообщение пользователя:** справа, фон `#242424`, радиус 12 12 4 12 (острый угол снизу справа),
  текст 16/24.
- **Ответ агента:** слева без фона; шапка — значок + словесный знак serif + бейдж модели «Lite»
  (12 px, рамка `#ffffff1f`, радиус 6). Под ней «Working for 26s» → «Worked for 1m 27s ›» (14 `#8c8c8c`).
- **Текст агента** 16/24 `#e6e6e6` чередуется с группами шагов.
- **Группа шагов:** заголовок-сводка «Searched 3 queries · Browsed 5 pages ⌄» (14 `#8c8c8c`),
  по клику раскрывается список; справа время. Строка шага: иконка инструмента 16 px
  (поиск, компас для браузера) + однострочное описание 14 `#8c8c8c` с обрезкой посередине «…».
- **Индикатор работы:** пульсирующая голубая точка + «Thinking»; токен `--background-thinking`
  намекает на shimmer-градиент по тексту.
- **Результат:** таблица (рамка `#ffffff0f`, радиус 12), ссылки синим, карточка файла
  (иконка типа, имя с обрезкой, «Spreadsheet · 394 B»), кнопка «View all files in this task».
  Ниже: «✓ Task completed» зелёным, копировать, повторить, время, оценка звёздами.
  Затем 3 предложенных следующих вопроса строками со стрелкой →.
- **Над композером** во время работы: миниатюра экрана агента + «Working» с точкой.
  Плейсхолдер меняется на «Message Manus», кнопка отправки становится «стоп» (белый круг, чёрный квадрат).
  Под композером дисклеймер 12 `#8c8c8c`.
- **Панель «компьютера агента»** (открывается кликом по миниатюре, делит экран пополам):
  - вкладка «Manus's computer» с «+» для новых вкладок, кнопки развернуть и закрыть;
  - строка состояния: «Manus is using Browser | https://…» или «Manus is using Editor | Creating file …»;
  - контент: страница из браузера **в виде отрендеренного Markdown**, а не скриншот; файлы — моноширинным текстом;
  - внизу таймлайн: ⏮ ⏭, синяя шкала прогресса, «● Live»; при перемотке назад — пилюля
    «▷ Jump to live»; под шкалой статус («Working» / «✓ Task completed»).
- **Меню задачи (⋯):** фон `#242424`, радиус 12, padding 4, ширина ~186;
  тень-стек: внутреннее кольцо `#ffffff24` 1px + внешнее `#00000047` 1px + `0 24px 24px -12px #00000029`.
  Строки 36 px, padding 8, радиус 8, иконка + 14 px, разделители, подменю с ›,
  деструктивный пункт «Delete» `#eb4d4d`.
- **Наведение на задачу в сайдбаре:** всплывающее превью с названием и временем.

## Иконки
- Библиотека **Lucide** (класс `lucide lucide-*`): stroke 2, `fill: none`, `stroke: currentColor`,
  viewBox 24, размеры 14 / 16 / 18 px. Цвет — через токены `--icon-primary/secondary/tertiary`.
- Немного собственных иконок 18×18 (бренд, специальные действия).
- Примеры: square-pen (новая задача), monitor (компьютеры), library-big, panel-left, search,
  ellipsis, plus, chevron-right/up, arrow-right, copy, check, download, earth, list-filter,
  file-search-corner, square-chart-gantt, hand-heart.

## Анимации (замерено покадрово)
- Своих `@keyframes` почти нет: мигание курсора редактора, спиннер и полоса прогресса загрузки страниц.
- Основа — CSS-переходы в стиле Tailwind:
  - цвет/фон/рамка при наведении: **150 мс**, `cubic-bezier(0.4, 0, 0.2, 1)` (24 элемента на экране);
  - opacity / transform: 150–200 мс, та же кривая;
  - фон кнопок: 150 мс `cubic-bezier(0, 0, 0.2, 1)`.
- **Сворачивание сайдбара:** `width` 300 → 52 px за **200 мс** `cubic-bezier(0.4, 0, 0.2, 1)`,
  текст исчезает раньше ширины.
- **Модалка:** только fade (opacity 0 → 1 примерно за 150 мс, к 200 мс полностью), без масштаба
  и сдвига; затемнение `#00000099` появляется сразу.
- **Пульсирующая точка** «Thinking» / «Working».
- Запись взаимодействий: `~/Downloads/reference-ui-interactions.gif` (13 кадров).
